# SuperNote plugins

## [AI Task Export](SnAITasks/)

A Supernote plugin (Manta, Nomad) that turns handwritten to-dos into tasks with AI. Choose Claude or OpenAI, and
send tasks to Amazing Marvin or Todoist. Export a page, chosen pages, a whole note, headings you mark, or a lasso
selection. Uses your own API keys, which stay on the device.

See [SnAITasks/README.md](SnAITasks/README.md) for setup, building, and how it works.
